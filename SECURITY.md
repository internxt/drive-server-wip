# Security Policy

## Supported versions

Only the latest commit on `master` is supported; it is what runs in production.

## Reporting a vulnerability

Please report security vulnerabilities privately by email to **hello@internxt.com**, with "Security" in the subject line. Do not open a public GitHub issue or pull request for them.

Include as much of the following as you can:

- The affected endpoint, module or file.
- Steps to reproduce, or a proof of concept.
- The impact you observed or expect.

We will acknowledge your report and keep you informed while we work on a fix.
